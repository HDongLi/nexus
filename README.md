全新重写中的 nexus：前后端完全分离、契约驱动、面向智能体并行开发的 Web 平台内核。

| 项 | 内容 |
|---|---|
| 状态 | 2026-11-26 开工。骨架已能运行：`pnpm dev` 一条命令起全栈。清点分类做完了，等裁决 |
| 先读 | [`docs/charter.md`](docs/charter.md)（任务书）。人读 §0–§2、§8–§10、§12 |

## 跑起来

前提：Node 24.12 以上，pnpm 12。

```sh
pnpm install
pnpm dev
```

终端会打出两个地址：后端的健康探测和页面。端口从 4260 起自动找空闲的，不假设它们空着。Ctrl+C，两个进程一起停。

开发库是进程内的 Postgres（PGlite），第一次启动自动建表，数据落在 `apps/api/.data/`，不需要先装数据库。设了 `DATABASE_URL` 就连真库。

## 检查

```sh
pnpm verify      # 提交前跑：格式、lint、依赖方向、类型、单元测试、集成测试、契约一致性、迁移可重放
pnpm gate:l3     # 发布前跑：在真浏览器里走一遍
```

| 级别 | 管什么 | 预算 | 冷缓存实测（2026-11-26） |
|---|---|---|---|
| L0 | 格式、lint、依赖方向、编译器版本、请求路径零同步、任务范围 | 10 秒内 | 2 秒 |
| L1 | 类型检查、单元测试 | 30 秒内 | 7.6 秒（装完依赖后的第一次约 15 秒） |
| L2 | 集成测试、契约一致性、迁移可重放 | 5 分钟内 | 10 到 18 秒 |
| L3 | 端到端 | 按需 | 14.5 秒 |

## 目录

| 路径 | 内容 |
|---|---|
| `AGENTS.md` | 代理入口：命令、地图、铁律 |
| `apps/api` | 后端应用：装配模块、中间件、进程生命周期。没有业务 |
| `apps/web` | 前端单页应用：路由与页面装配 |
| `modules/` | 领域模块，业务唯一的住处 |
| `packages/` | 不含业务的可复用件：生成的契约客户端、共享 schema、数据库接入、界面件、工程配置 |
| `tools/` | 质量闸、模块脚手架、开发启动器 |
| `docs/charter.md` | 任务书 |
| `docs/adr/` | 架构决策记录：编号、背景、决定、后果 |
| `docs/changes/` | 变更提案：提案、设计、任务卡 |
| `docs/parity/` | 旧系统的清点、裁决清单、缺陷待办 |
| `docs/strategy/` | 策略文档，持有者自管，不入库 |

## 现在在做什么

先把旧系统的每一条路由清点一遍，再写规格。旧系统是需求的来源，不是产品的定义：换一家单位还要的进内核，只有这家单位才这样的进定制包，没人用的退役。

- 服务端 272 条路由，分六批清点，结论在 [`docs/parity/routes.csv`](docs/parity/routes.csv)。
- 本机端 74 条路由，随本机端退役，逐条记下能力由谁接。
- 判不准的汇总成裁决清单，只拿这一张清单问人。

工作说明与数据格式在 [`docs/parity/SCHEMA.md`](docs/parity/SCHEMA.md)。
