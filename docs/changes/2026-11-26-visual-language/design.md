# 设计：视觉语言底座

跟着 [proposal.md](proposal.md)。规则和每条取值的来历在决策记录 [0004](../../adr/0004-视觉语言.md)，这里记落地的形状、验过什么、没做什么。

## 形状

### 取值都在一个文件里

`packages/ui-kit/src/styles.css` 是全仓唯一写数值的地方，页面和组件只用名字。

| 类别 | 名字 | 浅色 | 深色 |
|---|---|---|---|
| 页面底 | `background` | `#ffffff` | `#151517` |
| 侧栏底 | `surface` | `#f9fafb` | `#0f1115` |
| 卡片底 | `card` | `#ffffff` | `#232324` |
| 正文 | `foreground` | `#0f1115` | `#f9fafb` |
| 说明 | `ink-2` | `#61666b` | `#cfd3d6` |
| 标签 | `ink-3` | `#81858c` | `#adb2b8` |
| 占位 | `ink-4` | `#adb2b8` | `#81858c` |
| 强调 | `primary` | `#2b59c3` | `#9db8ff` |
| 边框 | `border`、`border-strong` | 墨 9%、16% | 白 9%、16% |
| 悬停底 | `fill`、`fill-strong` | 墨 4%、8% | 白 5%、10% |
| 层次 | `shadow-soft`、`shadow-panel`、`shadow-prominent` | 半像素描边加两层柔影 | 同左，影子换成黑 |

| 字阶 | 字号 / 行高 | 用在 |
|---|---|---|
| `text-caption` | 12 / 18 | 时间、请求号、页脚 |
| `text-ui` | 14 / 22 | 界面文字的默认值：表格、表单、导航 |
| `text-body` | 16 / 26 | 读的内容、页头标题 |
| `text-title` | 22 / 32 | 页面大标题（骨架页没有用） |

圆角三档：`rounded-control` 10、`rounded-card` 12、`rounded-panel` 16，胶囊和圆点用全圆。版心两档：`--container-read` 800、`--container-wide` 1120。

### 组合件

| 件 | 作用 |
|---|---|
| `AppShell` | 左侧栏 240 像素，右侧滚动区。窄于 768 像素时侧栏收进抽屉 |

图标用 `lucide-react`，只用线性的，尺寸只有 16 和 20 两种。

### 页面

骨架页「系统状态」：页头放标题、一句说明和刷新按钮；下面两张面板，一张健康状态，一张启动信息。需要登录的接口回 501，卡里用常显的提示把原因和请求号摆出来。

## 今天验过什么

全部在开发机上做。

| 验的是什么 | 结果 |
|---|---|
| `pnpm verify` | L0、L1、L2 全绿；任务范围闸在任务分支上报「越界 0 个」 |
| `pnpm gate:l3` | 3 条端到端用例在真浏览器里通过 |
| 无头浏览器截图：1440 宽的浅色与深色，430 宽的窄屏 | 正文 14 / 22，页头标题 16 号半粗，侧栏 240，加载的网络字体 0 个 |
| 窄屏抽屉 | 430 宽下点页头的菜单按钮，侧栏滑到最左、遮罩出现；按 Esc、点遮罩、点任一导航项都会收起 |
| 取值用对没有 | 全仓检索第三、四级墨的用法：句子都用二级，三级只有标签和辅助信息 |

过程中抓到并修掉的问题：

1. **时间显示成了「413」。** `toLocaleString` 带毫秒选项时，Chromium 回的不是时间。改成自己拼（`apps/web/src/lib/time.ts`），配两条单元测试。
2. **窄屏下整页被挤折。** 侧栏定宽 240，在 430 像素宽的窗口里内容区只剩一条。侧栏在 768 以下收进抽屉，页头加一个菜单按钮。
3. **句子用了对比度不够的墨。** 页头说明、加载中的提示、输入框的补充说明原先用三级墨（白底对比度 3.7），改成二级（5.8）。
4. **lint 拦下一个没有用的参数。** `SidebarItem` 为了不往下透传 `type` 把它解构出来，lint 要求改名成下划线开头。

## 没做、留给后面的

- **三家应用内的界面没有看到。** Claude 在本机网络下不可达，ChatGPT 连接超时，WorkBuddy 的应用要微信登录。这三家的结论只到官网和样式表这一层，0004 里逐家标了。
- **对话流、表格、表单的专项规则。** 等第一个这样的页面开工时再定，现在定是凭空想。
- **主题切换的入口。** 深色的一套令牌有了，页面上还没有切换的开关，也没有跟随系统。
- **标志是临时的。** 一个圆环加一点的几何图形。
